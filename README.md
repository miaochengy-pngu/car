# STC89C52RC 红外循迹小车

本仓库对应课程套件中的 51 单片机两轮循迹小车。

现在已经找到与实物一致的商品/原理图资料，因此不再按通用小车猜引脚。当前代码与接线按这块实际控制板的 PCB 丝印和原理图整理。

## 已确认硬件

- 主控：STC89C52RC-DIP40，11.0592 MHz
- 主控板：带专用“红外循迹接口”和 6 针电机控制排针
- 电机驱动：L298N 双 H 桥模块
- 循迹模块：双路红外循迹板，接口为 OTL / OTR / GND / VCC
- 电机：2 × TT 直流减速电机
- 电源：4 × AA 电池盒（约 4–6 V，视电池类型/电量而定）

## 原厂主控板关键引脚

原理图给出了两组循迹接口：

- 循迹接口 1：P1.4 / P1.5
- 循迹接口 2：P3.4 / P3.5

本套件白色“红外循迹接口”使用第二组，因此代码使用 P3.4/P3.5。

主控板 PCB 上还有一个专门给 L298N 使用的 6 针控制排针，丝印对应关系为：

- ENB -> P1.0
- IN4 -> P1.1
- IN3 -> P1.2
- IN2 -> P1.3
- IN1 -> P1.4
- ENA -> P1.5

因此不要再使用旧版临时映射 P3.2/P3.3 或 P1.6/P1.7。

## 最推荐的实际接线

### 1. 循迹模块

直接使用套件附带的 4P 双头端子线：

    黑色循迹模块白色 4P 接口
                  |
                  | 4P 双头线
                  v
    主控板白色“红外循迹接口”

这根线同时包含 VCC、GND、OTL、OTR，不需要自己再用四根杜邦线拆开接。

主控内部信号对应：

    OTL（左循迹） -> P3.5
    OTR（右循迹） -> P3.4

如果实车测试发现左、右修正刚好完全相反，只需在 main.c 中交换 TRACK_LEFT 和 TRACK_RIGHT。

### 2. L298N 控制线

L298N 控制端与主控板专用 6 针排针按同名连接：

    主控板 ENA -> L298N ENA
    主控板 IN1 -> L298N IN1
    主控板 IN2 -> L298N IN2
    主控板 IN3 -> L298N IN3
    主控板 IN4 -> L298N IN4
    主控板 ENB -> L298N ENB

对应 MCU：

    ENA = P1.5
    IN1 = P1.4
    IN2 = P1.3
    IN3 = P1.2
    IN4 = P1.1
    ENB = P1.0

当前 main.c 将 ENA/ENB 恒置高，先完成基本循迹；后续需要调速时可以直接在 ENA/ENB 上加入软件 PWM。

### 3. 两个电机

按商品接线示意图：

    左电机 -> L298N 左马达输出
    右电机 -> L298N 右马达输出

推荐先按厂家示意图的极性：

    左电机：上端子接黑线，下端子接红线
    右电机：上端子接红线，下端子接黑线

第一次必须把车轮架空测试。如果“前进”时某侧反转，只交换那一侧电机的两根线。

### 4. 电源

这套板本身已经为小车设计了电源输入/输出。

主控板标有：

- 4–6V DC 电源输入口
- 4–6V DC 电源输出口

L298N 标有：

- 6–12V DC 输入
- GND / 5V 辅助接口

对于套件自带四节 AA 电池盒，推荐按原套件结构接：

    4 节 AA 电池盒
          |
          v
    主控板 4–6V DC 输入
          |
          | 主控板 4–6V DC 输出
          v
    L298N 6–12V DC 输入

使用套件里的 2P 单头端子线，从主控板“4–6V DC 输出”引到 L298N 螺丝电源端。

电源极性一定按红正、黑负接：

    红线 -> +
    黑线 -> GND / -

这样主控、循迹模块和 L298N 天然共地。

## 循迹逻辑

模块商品说明写明：

- 到黑线：对应循迹指示灯灭
- 非黑线：对应循迹指示灯亮

当前程序按常见比较器数字输出设置为：

| OTL | OTR | 动作 |
|---:|---:|---|
| 0 | 0 | 前进 |
| 1 | 0 | 左修正 |
| 0 | 1 | 右修正 |
| 1 | 1 | 停车 |

如果实测逻辑相反，把 main.c 中：

    #define TRACK_BLACK_LEVEL 1

改为：

    #define TRACK_BLACK_LEVEL 0

## 第一次通电测试

不要直接把小车放地上跑。

先架空车轮：

1. 打开主控板和 L298N 电源开关。
2. 白纸放在两个循迹探头下面：两轮应向“前进”方向转。
3. 只让左探头压黑线：应进行左修正。
4. 只让右探头压黑线：应进行右修正。
5. 两探头同时压黑线：当前程序停车。
6. 确认无误以后再落地跑。

## Keil C51

1. 新建 Keil uVision C51 工程。
2. 目标选择兼容 8051/AT89C52 即可。
3. 加入仓库根目录 main.c。
4. Options for Target -> Output -> 勾选 Create HEX File。
5. Build。
6. 使用 STC-ISP 选择 STC89C52RC 烧录。
