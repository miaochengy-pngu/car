# STC89C52RC 红外循迹小车

本仓库对应清翔电子 A11 / 同系列 C51 两轮红外循迹小车。

现在已有：
- 用户实物 PCB 高清照片
- 《A套餐红外循迹组装调试指南》
- 实物主控板丝印
- 实物 L298N 驱动板丝印

因此当前代码不再使用通用小车的临时引脚猜测，而按本套件资料编写。

## 已确认硬件

- 主控：STC89C52RC-DIP40
- 晶振：11.0592 MHz
- 电机驱动：L298N 双 H 桥
- 循迹模块：双路 TCRT5000 + LM393，接口 OTL / OTR / GND / VCC
- 电机：2 × TT 减速电机
- 电源：4 × 1.5 V AA 电池

## 1. 电机控制引脚

手册与实物 PCB 完全一致：

| L298N | C51 主控板 | MCU |
|---|---|---|
| ENB | P10 | P1.0 |
| IN4 | P11 | P1.1 |
| IN3 | P12 | P1.2 |
| IN2 | P13 | P1.3 |
| IN1 | P14 | P1.4 |
| ENA | P15 | P1.5 |

六根杜邦线按同名顺序连接，不看线的颜色。

## 2. 红外循迹接口

使用套件的 XH2.54 4P 排线直接连接：

    黑色双路循迹模块
          |
          | 4P XH2.54 排线
          v
    主控板“红外循迹接口”

实物主控板接口丝印对应：

    OTL -> P3.5
    OTR -> P3.4
    GND -> GND
    VCC -> VCC

所以 main.c 当前定义为：

    TRACK_LEFT  = P3^5
    TRACK_RIGHT = P3^4

## 3. 电机线

严格按手册：

    左电机红线 -> OUT2
    左电机黑线 -> OUT1

    右电机红线 -> OUT4
    右电机黑线 -> OUT3

如果你已经完全按这套线序接好，就不要再通过交换电机线来“试方向”，代码已经按手册方向表修正。

## 4. 电源

如果使用套件推荐的 4 节 1.5 V AA 电池：

    电池盒
      |
      v
    C51 主控板 5V / 4~6V 电源输入
      |
      | 主控板电源输出
      v
    L298N 电源输入

从主控板给 L298N 供电时：

    主控板 VCC -> L298N +
    主控板 GND -> L298N -

注意：
- 该接法只适用于总电压不超过 6 V 的 4 节 AA 方案。
- 红线必须对 VCC/+，黑线必须对 GND/-。
- 如果以后使用超过 6 V 的其他电源，不要直接送入 C51 主控板 5V 输入；应按手册改为先给 L298N 供电，再由驱动板 5V 输出给 C51。

## 5. L298N 方向真值表

手册明确给出了本套件左右电机方向：

| ENA | IN1 | IN2 | 左电机 |
|---:|---:|---:|---|
| 0 | x | x | 停止 |
| 1 | 0 | 0 | 停车 |
| 1 | 1 | 0 | 正转 |
| 1 | 0 | 1 | 反转 |
| 1 | 1 | 1 | 停车 |

| ENB | IN3 | IN4 | 右电机 |
|---:|---:|---:|---|
| 0 | x | x | 停止 |
| 1 | 0 | 0 | 停车 |
| 1 | 1 | 0 | 反转 |
| 1 | 0 | 1 | 正转 |
| 1 | 1 | 1 | 停车 |

这意味着左右电机“前进”的 H 桥电平本来就不一样：

    左前进：IN1=1, IN2=0
    右前进：IN3=0, IN4=1

main.c 已按这张表修正。

## 6. 红外传感器逻辑

手册说明：

- 红外反射弱或没有反射：输出高电平，指示灯灭
- 红外反射强：输出低电平，指示灯亮

在白底黑线场地中：

    白底 -> 反射强 -> 输出 0 -> 指示灯亮
    黑线 -> 反射弱 -> 输出 1 -> 指示灯灭

所以程序固定使用：

    #define TRACK_BLACK_LEVEL 1

默认循迹逻辑：

| 左 OTL | 右 OTR | 动作 |
|---:|---:|---|
| 0 | 0 | 前进 |
| 1 | 0 | 左修正 |
| 0 | 1 | 右修正 |
| 1 | 1 | 停车 |

其中 1/1 停车是本仓库的控制策略，方便把横向黑线当终点；手册本身只定义传感器电平，没有规定必须如何处理 1/1。

## 7. 循迹模块调试

手册推荐：

1. 用 XH2.54 排线接到主控板循迹接口。
2. 先只开主控板电源。
3. 在白色桌面贴约 3 cm 宽黑色电工胶带。
4. 调试时传感器距离桌面约 2 cm。
5. 传感器在黑线上：对应指示灯应灭。
6. 不在黑线上：对应指示灯应亮。
7. 非黑线时灯不亮：顺时针调电位器。
8. 黑线时灯不灭：逆时针调电位器。
9. 电位器不要拧到机械极限。

灵敏度调好后再固定到车头。

## 8. 第一次烧录后的测试

先把两个车轮悬空，不要直接落地跑。

1. 打开主控板电源。
2. 打开 L298N 电源开关。
3. 两个传感器都对白底：两轮应让整车“前进”。
4. 左探头压黑线：左轮停、右轮前进。
5. 右探头压黑线：左轮前进、右轮停。
6. 两探头同时压黑线：两轮停止。

如果第 3 步整车方向不对，先检查电机线是否严格为：

    左：红 OUT2，黑 OUT1
    右：红 OUT4，黑 OUT3

不要先改程序。

## 9. Keil C51

1. 新建 Keil uVision C51 工程。
2. 目标可选择兼容 8051 / AT89C52。
3. 加入仓库根目录 main.c。
4. Options for Target -> Output -> 勾选 Create HEX File。
5. Build。
6. 用 STC-ISP 选择 STC89C52RC 烧录。
