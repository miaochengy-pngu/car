# STC89C52RC 红外循迹小车

当前版本采用最简单的双数字红外实时循迹逻辑。

## 当前控制逻辑

为了避免“指示灯灭到底对应 MCU 的 0 还是 1”判断错误导致整车上电不走，
当前直接按左右传感器是否一致来处理：

```text
00 -> 直行
11 -> 直行
10 -> 左转
01 -> 右转
```

也就是：

```text
左右传感器状态相同
-> 继续前进

只有左边为 1
-> 左转

只有右边为 1
-> 右转
```

这一版不使用 PID、滤波、延时锁定、历史方向或复杂状态机。

## A11 主板引脚

电机：

| L298N | MCU |
|---|---|
| ENB | P1.0 |
| IN4 | P1.1 |
| IN3 | P1.2 |
| IN2 | P1.3 |
| IN1 | P1.4 |
| ENA | P1.5 |

红外：

```text
OTL -> P3.5
OTR -> P3.4
```

## 速度参数

```c
#define RUN_LEFT_SPEED           90
#define RUN_RIGHT_SPEED          90

#define TURN_INNER_SPEED       -100
#define TURN_OUTER_SPEED        100
```

负数表示该侧电机反转。
