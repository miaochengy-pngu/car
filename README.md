# STC89C52RC 红外循迹小车

当前版本先绕过软件 PWM 和 Timer0，直接把 L298N 的 ENA / ENB 拉高，以排除“PWM 中断没有工作导致电机始终没有使能”的问题。

## 电机控制

```text
ENB -> P1.0
IN4 -> P1.1
IN3 -> P1.2
IN2 -> P1.3
IN1 -> P1.4
ENA -> P1.5
```

非零电机命令时，对应 EN 直接置 1；不再依赖 Timer0 PWM。

## 当前循迹逻辑

```text
00 -> 直行
11 -> 直行
10 -> 左转（左轮反转、右轮正转）
01 -> 右转（左轮正转、右轮反转）
```

因此当前四种传感器状态都不会让整车停住。若烧录后仍然完全不动，应优先检查 A11 板的 ENA/ENB/IN1~IN4 实际接线、电机供电和驱动通道，而不是继续修改循迹算法。
