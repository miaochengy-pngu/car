# 硬件资料核对记录

当前硬件定义以两类证据为最高优先级：

1. 用户自己的实物 PCB 丝印；
2. 《A套餐红外循迹组装调试指南》。

通用开源资料只作为辅助参考，不再用于决定引脚。

## 1. 主控

- STC89C52RC-DIP40
- 11.0592 MHz 晶振
- Keil C51 / REG52.H

实物主控板已经清楚看到电机控制接口丝印：

    ENB -> P1.0
    IN4 -> P1.1
    IN3 -> P1.2
    IN2 -> P1.3
    IN1 -> P1.4
    ENA -> P1.5

实物主控板红外循迹接口丝印：

    P3.5
    P3.4
    GND
    VCC

结合循迹模块接口顺序 OTL / OTR / GND / VCC，当前代码采用：

    OTL -> P3.5
    OTR -> P3.4

## 2. L298N

手册明确给出 6 根控制线连接关系：

    ENB -> P10
    IN4 -> P11
    IN3 -> P12
    IN2 -> P13
    IN1 -> P14
    ENA -> P15

电机接线：

    左电机红线 -> OUT2
    左电机黑线 -> OUT1

    右电机红线 -> OUT4
    右电机黑线 -> OUT3

手册方向真值：

左电机：
- ENA=1, IN1=1, IN2=0 -> 正转
- ENA=1, IN1=0, IN2=1 -> 反转

右电机：
- ENB=1, IN3=1, IN4=0 -> 反转
- ENB=1, IN3=0, IN4=1 -> 正转

因此程序中的左右“forward”电平必须不同。

## 3. 红外循迹模块

模块：

- TCRT5000 反射传感器
- LM393 比较器
- 3.3~5 V 工作电压
- 数字 0/1 输出
- 两路灵敏度独立可调

手册明确逻辑：

- 无反射/反射弱 -> 输出高电平 -> 指示灯灭
- 反射足够强 -> 输出低电平 -> 指示灯亮

白底黑线环境下：

    白底 -> 0
    黑线 -> 1

因此代码使用：

    #define TRACK_BLACK_LEVEL 1

## 4. 电源

4 节 1.5 V AA 电池串联时：

    电池盒 -> C51 主控板 5V/4~6V 输入

再由主控板电源输出给 L298N：

    主控 VCC -> L298N +
    主控 GND -> L298N -

手册特别强调：
- 这种接法要求电池总电压不超过 6 V；
- 红线必须接 VCC/+；
- 黑线必须接 GND/-；
- 如果使用超过 6 V 的其他电源，应先给 L298N 供电，再从 L298N 5V 输出给 C51。

## 5. 循迹调试条件

手册建议：

- 白色/浅色反光桌面；
- 黑色绝缘胶带约 3 cm 宽；
- 调试传感器时距离桌面约 2 cm；
- 黑线上灯灭，白底灯亮；
- 非黑线灯不亮：顺时针增加灵敏度；
- 黑线上灯不灭：逆时针降低灵敏度；
- 电位器不能强行拧到底。
